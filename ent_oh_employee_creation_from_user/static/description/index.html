Frequently Asked Questions

How does the automatic employee creation feature work when a user is created?

When a new user is created in the system, this module automatically generates an employee record linked to that user. No additional steps are required — the employee is created and associated in the background as part of the user creation workflow.

Will an employee record be created for every new user?

Yes. Whenever a new user is created in the Odoo system, this module will automatically trigger the creation of a corresponding employee record. The employee and user will be linked to each other within the HR module.

What modules are required to install this module?

This module is a component of the Open HRMS suite. The base Odoo HR module (hr) and the Open HRMS Core (ohrms_core) are required dependencies. Ensure these are installed before activating this module.

Which Odoo version is this module compatible with?

This module is compatible with Odoo 18 Enterprise. It is designed specifically for use within the Enterprise edition of Odoo 18.
