Key Highlights

Resignation Process

Easily create, manage, and track employee resignations with a structured workflow from draft to approval.

Approval Workflow

Higher level officers can review, approve, or reject resignation requests submitted by employees.

Resigned Employees

Filter and view resigned or fired employees separately. Employee records are automatically deactivated upon approval.

Notice Period Tracking

Automatically calculates and tracks the notice period from the employee's contract, with approved last day computation.

Resignation Type

Distinguish between normal resignations and terminations. Each type triggers the appropriate status on the employee record.

Automated Status Updates

A scheduled cron job automatically deactivates employees and revokes system access once the last working day is reached.

Frequently Asked Questions

How can an employee submit a resignation request?

Go to Resignation → Resignation Request and click New. Fill in the required details including the reason and expected last day, then confirm the request.

Who can approve or reject a resignation request?

Users with the HR Manager role can approve or reject resignation requests. Employees can only create requests for themselves unless they have HR officer access.

What happens to the employee account after approval?

Once the last working day is reached, the employee record is automatically archived, the user account is deactivated, and the resigned or fired flag is set on the employee profile.

Does this module require the Payroll module?

No, the Payroll module is optional. If installed, the module will automatically fetch the notice period from the employee's active contract. Without it, the module works normally without contract-based notice period calculation.

Which Odoo version is this module compatible with?

This module is built and tested for Odoo 19 Enterprise. It depends on the hr and ent_hr_employee_updation modules and is compatible with Odoo.sh deployments.
