Key Highlights

Advanced Employee Fields

Adds personal mobile, joining date, ID expiry date, passport expiry date, and attachment fields directly to the employee master form.

Family Information

Maintain a complete family/dependant details table per employee including relation, name, contact number, and date of birth.

Expiry Notifications

Automated scheduled reminders notify employees by email when their ID or passport is approaching its expiry date.

Notice Period Configuration

Configure a default notice period in settings and track it per employee. Supports global default days with per-employee override capability.

Document Attachments

Attach scanned copies of employee ID and passport directly on the employee form for easy access and HR record keeping.

Spouse Auto-fill

Automatically populates the family table with spouse details when spouse name and birthdate are entered in the private information tab.

Frequently Asked Questions

How is the employee joining date set?

In Odoo 19, the joining date is a manually editable field on the employee form under Personal Information. HR managers can set or update it directly as needed.

How do document expiry notifications work?

A scheduled cron job runs daily. It sends an email to the employee's work email address 14 days before their ID expires and 180 days before their passport expires.

How do I set a default notice period?

Go to Settings → Employees → Notice Period section. Enable the toggle and set the number of days. This default will be pre-filled for all new employee records.

Can I add multiple family members per employee?

Yes. The Dependance Details table on the employee form allows you to add unlimited family members, each with their own relation type, name, contact number, and date of birth.

Which Odoo version is this module compatible with?

This module is built and tested for Odoo 19 Enterprise. It requires the hr_payroll module as a dependency since hr.contract is no longer a standalone module in Odoo 19.
