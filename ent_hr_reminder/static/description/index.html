Key Highlights

Reminder

Reminders is an effective module that helps to memorise all your important dates and ensures no critical event is ever missed.

Reminder for Model

Set reminders on any model (e.g. Sales, HR, Project) and select the corresponding date fields to compare and trigger alerts.

Special Dates

Eases company workload by tracking special dates such as expiration dates, deadlines, and assigned dates all from one place.

Flexible Search Options

Search reminders by Today, a Set Period, or a specific Set Date — giving full control over when and how reminders are triggered.

Define a reminder expiry date so notifications automatically stop showing after a certain point, keeping the systray clean and relevant.

Systray Integration

Frequently Asked Questions

What types of reminders can I set?

Reminders can be set for a specific date, a defined period, or for today. This flexibility helps you stay organized and manage tasks efficiently across any model in Odoo.

Can I modify or delete a scheduled reminder?

Yes, reminders can be edited or deleted through the module's list view before they are triggered. HR managers have full create, edit, and delete access.

Can reminders be set for non-HR models like Sales or Projects?

Yes. While this is an HR module, you can configure reminders for any model available in your Odoo instance by selecting the model and the appropriate date field when creating a reminder.

Where do the reminders appear in Odoo?

Active reminders appear as a bell icon in the Odoo top navigation systray. Clicking the bell shows a dropdown list of current reminders. Selecting one and clicking View opens the filtered list of related records directly.
