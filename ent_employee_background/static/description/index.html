Frequently Asked Questions

What is the Enterprise Open HRMS Employee Background Verification module?

It is an Odoo 19 addon developed by Cybrosys Technologies that streamlines employee background checks within the HR module. It helps HR managers store, assign, and track background verifications through external agents, with a dedicated website portal for agent submissions.

How do I configure a verification agent?

Go to Contacts, open the partner record of the agent, and tick the "Is Agent" checkbox. Make sure a valid email address is entered so they receive the automated assignment notification.

How does the agent access the portal to submit a verification?

From the agent's contact record, use the Action menu → "Grant Portal Access" to send them a portal invitation. Once logged in, they can see their assigned verifications under "Employee Verification" in their portal home page.

Can I track educational qualifications through this module?

Yes. You can attach the employee's resume and educational certificates to the verification record, and the assigned agent can review these documents from the portal to verify education, certifications, and degrees.

Which Odoo version is this module compatible with?

This module is built and tested for Odoo 19 Enterprise. It depends on hr_recruitment, mail, contacts, portal, and website modules.
