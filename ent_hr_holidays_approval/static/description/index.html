Frequently Asked Questions

What is the OpenHRMS Leave Multi-Level Approval module?

The OpenHRMS Leave Multi-Level Approval module enhances the leave management system in Odoo by introducing multiple approval levels. It ensures that leave requests go through a structured approval hierarchy before being finalized.

How does the multi-level approval process work?

With this module, a leave request submitted by an employee must pass through predefined approval levels, where each assigned manager or approver must approve the request before final confirmation. The number of approval levels can be configured based on company policies.

Can a leave validator reject a leave request?

Yes, any assigned leave validator can refuse a leave request at any stage of the approval process. They can also add comments explaining the reason for refusal.
